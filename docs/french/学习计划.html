12 周学习计划

配合「零起点标准法语」互动学习台使用 · 每周 5 天，每天 40–60 分钟

每天怎么学（固定套路）

  1. 5 分钟：打开学习台 →「复习」，把今天到期的卡片过一遍（这是最重要的一步，别跳）
  2. 25–35 分钟：学 1 节新课。先听发音 → 看讲解 → 点例句听读 → 跟读三遍
  3. 10 分钟：「测验」抽 10 题，检验今天学的词和句
  4. 5 分钟：把错题和记不住的词抄进自己的小本子（手写一遍记得牢）

三条原则

  • 发音优先：第 1–2 周只练字母和拼读，别急着学语法。ع غ ق ح 发不对，后面每个词都要返工。
  • 一定要出声：法语的鼻化元音、[y] 和连诵，光看不读等于没学。每句例句都跟读。
  • 别追求一次记牢：阿语词汇遗忘快是正常的，靠「复习」里的间隔重复把它捞回来，别硬背。
第 1 周

认识法语和 26 个字母

  • 26 个字母的法语读法跟英语不一样（G 读「热」、J 读「日」、R 读「艾赫」、U 读「于」）
  • 五个变音符号 é è ê ç ù 各管什么
  • a e i o u 五个元音 + 最重要的 [y]（tu 的 u）
  • 每天跟读 10 分钟，先把 «tu / tout» 这两类音分清
第一节 法语与 26 个字母第二节 元音（一）： 与 []
第 2 周

鼻化元音与拼写规则

  • 四个鼻化元音 ɑ̃ ɛ̃ ɔ̃ œ̃：an / in / on / un
  • ch gn qu ph ç 这些字母组合怎么读
  • 字母 h 永远不发音；词末辅音多数不发音
  • 目标：看到任何带音标的法语词都能读出来
第三节 鼻化元音第四节 辅音与字母组合
第 3 周

连诵、节奏与名词入门

  • 省音 l' / j' / d' 和三类连诵（必连、禁连、可连）
  • 法语重音固定在词末，按节奏组念，不要学英语的重音
  • 名词有阴阳性，复数加 -s 但不发音
  • 本周开始造句：le livre / la table
第五节 连诵与省音第六节 重音、节奏与语调第七节 名词的性与数
第 4 周

冠词与形容词

  • 不定冠词 un / une / des 与 «c'est» 句型
  • 定冠词 le / la / les 与缩合冠词 au / aux / du / des
  • 形容词多数放名词后，但 grand / petit / bon 等短词放前面
  • 形容词必须跟名词的性数配合
第八节 不定冠词与「这是」第九节 定冠词与缩合冠词第十节 形容词的位置与配合
第 5 周

主有形容词与动词入门

  • mon / ton / son、notre / votre / leur 的配合对象是名词不是所有者
  • 主语人称代词 je / tu / il / elle / on / nous / vous / ils / elles
  • 什么是动词变位：词干 + 词尾，法语动词分三组
  • 练到能说「我的书」「你的老师」
第十一节 主有形容词第十二节 主语人称代词与动词变位入门
第 6 周

两个最重要的动词和第一组动词

  • être 和 avoir 的完整现在时变位，这两个必须背到滚瓜烂熟
  • -er 动词占法语动词九成：parler 的六个词尾 -e -es -e -ons -ez -ent
  • 重点：-ent 不发音，il parle 和 ils parlent 听起来一样
  • 练：用 aimer / habiter / travailler 各造三个句子
第十三节 和第十四节 第一组动词（-）
第 7 周

第二组动词与否定疑问

  • -ir 动词（finir / choisir）与不规则动词 aller / faire / venir
  • 否定 ne … pas 包住变位动词；元音前省音 je n'aime pas
  • 三种提问方式：升调、est-ce que、倒装
  • 疑问词 qui / que / où / quand / comment / pourquoi / combien
第十五节 第二组动词（-）与不规则动词 //第十六节 否定与疑问
第 8 周

两个「最近」时态与复合过去时

  • aller + 不定式 = 最近将来；venir de + 不定式 = 最近过去
  • 复合过去时 = avoir/être 现在时 + 过去分词
  • 重点：aller / venir / arriver / partir 等一批动词用 être 作助动词，过去分词要跟主语配合
  • 练：把上周的句子全部改成过去时
第十七节 最近将来与最近过去第十八节 复合过去时
第 9 周

未完成过去时与宾语代词

  • 未完成过去时 = nous 现在时去掉 -ons + -ais -ais -ait -ions -iez -aient
  • 复合过去时讲「发生了什么」，未完成过去时讲「当时是什么样」
  • 直接宾语代词 le / la / les，间接宾语代词 lui / leur
  • 代词放在变位动词前面：je le vois、je lui parle
第十九节 未完成过去时第二十节 宾语代词
第 10 周

代词式动词、命令式与数字

  • 代词式动词 se lever → je me lève，否定 je ne me lève pas
  • 命令式三种形式：parle / parlons / parlez；être 是 sois / soyons / soyez
  • 数字 1–100、序数词、时间与日期
  • 练：说出今天的日期和现在几点
第二十一节 代词式动词与命令式第二十二节 数字、时间与日期
第 11 周

日常场景

  • 问候与自我介绍、点餐与咖啡、购物、问路、住宿、求助
  • 把这些场景的固定说法整句背下来，不要逐词翻译
  • 重点练 tu 与 vous 的取舍
  • 本周不学新语法，只把前 10 周的东西用出去
第二十三节 日常场景
第 12 周

阅读与总复习

  • 读一篇短文，把 12 周的语法点全部串起来
  • 把错题本刷一遍，重点看动词变位和性数配合
  • 复习卡片里到期的全部过一遍
  • 尝试不带音标读一段法语新闻标题
第二十四节 阅读短文与综合复习
计划可根据自己的进度调整：跟不上就把一周拆成两周，学完比学快重要。
