选书

COLOPHON · DESIGN NOTES

这本书自己就是案例

这本书讲界面设计，所以它自己也得经得起看。下面是我们选的视觉语言，以及为什么。

风格：瑞士编辑设计 × 蓝图批注

整体取自瑞士国际主义（Swiss / International Typographic Style）：严格的网格、大号无衬线标题、编号小节、发丝线分隔、克制的红色强调。它像一本设计手册，而不是一张网页——这正好符合原书「手册」的气质。

互动实验的部分借了蓝图（Blueprint）的视觉语言：虚线框、角标、网格参考线、编号标签。读者一眼就能分清「这是书的内容」和「这是让你动手的地方」。

颜色

纸白背景降低长时间阅读的屏幕眩光；墨色正文保证对比度；瑞士红只出现在当前状态与关键操作上，不抢正文。

  • 纸白 Paper#f7f5f0背景 / 主画布
  • 墨 Ink#161514正文 / 标题
  • 石墨 Graphite#55514a次要文字 / 注释
  • 细线 Rule#e2ddd2分隔线 / 边框
  • 瑞士红 Swiss Red#e03131强调 / 当前状态
  • 蓝图蓝 Blueprint#2f5d8a互动实验 / 批注

字体

不加载网络字体：中文用系统黑体（Noto Sans CJK / PingFang SC / 微软雅黑），拉丁用 Helvetica / Arial 一脉。正文另外提供「宋体」阅读模式——在设置里可以随时切换，这也是原书「字重与对比度」一章的现场练习。

  • 界面设计章节标题 · 38–60px
  • 界面设计小节标题 · 27px
  • 界面设计小标题 · 18px
  • 界面设计正文 · 17px（可调）
  • 界面设计图注 · 13px
  • 界面设计微标签 · 12px

间距

所有间距来自 4 / 8 的倍数：4、8、12、16、24、32、48、64、96。章节之间用 96–128px 的留白，正文段落之间 24px，让「呼吸」成为默认而不是例外。

动效

动效只用来解释状态变化：滑块的实时反馈、实验面板的切换、灯箱的缩放。所有动画都尊重 prefers-reduced-motion。

技术

静态站点，没有前端框架：Python 把 Markdown 构建成 HTML，原生 JS 负责阅读器、13 个实验和 32 个实时重制界面。284 张插图转成 WebP 双尺寸，按需加载。全部代码在 GitHub。
